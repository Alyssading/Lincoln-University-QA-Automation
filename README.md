# 🎓 Lincoln University E2E Automation Suite

[![Playwright Tests](https://github.com/Alyssading/Lincoln-University-QA-Automation/actions/workflows/playwright.yml/badge.svg)](https://github.com/Alyssading/Lincoln-University-QA-Automation/actions)

## 📋 Project Overview
This repository contains a professional End-to-End (E2E) testing framework designed for **Lincoln University's official website**. Built with **Playwright**, it ensures core user journeys (like searching for courses) are functional and stable.

## ✨ Key Features
- **UI Automation:** Validates critical paths on the homepage and search modules.
- **Cross-browser Support:** Verified on Chromium, Firefox, and WebKit.
- **Smart Locators:** Implements Playwright's best practices (Role-based and Placeholder locators).
- **Automated Reporting:** Generates detailed HTML reports for test results.

## 🛠 Tech Stack
- **Engine:** [Playwright](https://playwright.dev/)
- **Runtime:** Node.js v22+
- **Language:** JavaScript
- **CI/CD:** GitHub Actions (Integrated)

## 🚀 Getting Started

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your Mac.

### 2. Installation
```bash

git clone [https://github.com/Alyssading/Lincoln-University-QA-Automation.git](https://github.com/Alyssading/Lincoln-University-QA-Automation.git)

# Enter the directory
cd Lincoln-University-QA-Automation

# Install dependencies
